# One Line, One Chill

One line of horror — a single sentence, under 200 characters, that frightens a reader in one breath. This entry writes that line to `entry.txt`.

> My daughter drew our family again tonight, and this time she drew five of us.

A child's drawing, a family of four, and one figure too many. The scare is what the line withholds: who the fifth person is, and whether the child drew them — or they drew themselves.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-one-chill-test node main.ts
cat /tmp/one-line-one-chill-test/entry.txt
```

Requires Node 22 or later. The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validating it is a single sentence of 1–200 characters.
